# Test Cases — Pinning Host Companies, Planning Routes, and Assigning Supervising Instructors

Step-by-step test cases for the feature [5. Pinning Host Companies, Planning Routes, and Assigning Supervising Instructors](../../design/feature-list.md), referencing the acceptance criteria in [acceptance-criteria](../acceptance-criteria.md) and the flow in [user-journey](../../design/user-journey.md).

| ID | Test case name | Precondition | Steps | Expected result | AC tested | FR/NFR code | Priority |
|---|---|---|---|---|---|---|---|
| TC-05-01 | Student pins the host company's location | The Student has the status "ready to apply for an internship" or is in the process of preparing to start the internship | 1. Log in with a Student account<br>2. Open the Google Map pinning page<br>3. Search for/select the host company's location and pin it | The system saves the coordinates with that Student's internship record and shows the pin to Supervising Instructors/the Internship Coordinator on the combined map | [FR-16 AC-1](../acceptance-criteria.md) | FR-16 | High |
| TC-05-02 | Use the pinned coordinates only for on-site supervision rounds (revised 2026-09-16) | The Student has already pinned the host company's location (continuing from TC-05-01) and there is a supervision round with a defined mode | 1. Log in with a Supervising Instructor account<br>2. Open a supervision round whose mode is set to "on-site"<br>3. Verify that the system uses the pinned coordinates to help plan that round's route<br>4. Open another supervision round whose mode is set to "online" and verify that no coordinate reference is enforced | The on-site supervision round uses the pinned coordinates to help plan the route, while the online supervision round does not enforce any reference to these pinned coordinates | [FR-16 AC-2](../acceptance-criteria.md) | FR-16 | High |
| TC-05-03 | Use the system to help group/plan supervision routes | Several Students have already pinned host company locations in the same semester (repeating TC-05-01 for multiple Students) | 1. Log in with a Supervising Instructor or Internship Coordinator account<br>2. Enable the function that helps group/plan supervision routes | The system groups host companies that are located near one another to support planning | [FR-17 AC-1](../acceptance-criteria.md) | FR-17 | Medium |
| TC-05-04 | Assign 1 Supervising Instructor per route group (new 2026-09-16) | The Internship Coordinator has at least 1 group of host companies grouped by nearby area (continuing from TC-05-03) | 1. Log in with an Internship Coordinator account<br>2. Open the Supervising Instructor assignment page for the arranged route group<br>3. Select 1 Supervising Instructor and assign them to be responsible for this group | The system saves the assignment and ensures every host company in the same group is assigned to the same instructor (a 1:1 relationship per FR-18) | [FR-32 AC-1](../acceptance-criteria.md) | FR-32 | High |
| TC-05-05 | Assign a Supervising Instructor manually even without full automation (new 2026-09-16) | The automatic grouping function (FR-17) does not yet cover every case | 1. Log in with an Internship Coordinator account<br>2. Manually select a host company that did not go through the automatic grouping result<br>3. Manually select a Supervising Instructor and assign them | The system accepts the manual assignment and records it the same as an assignment made through an automatically arranged route group | [FR-32 AC-2](../acceptance-criteria.md) | FR-32 | High |
| TC-05-06 | The map renders without lag when there are many pins | Pins for the host companies of an entire cohort of Students are shown on the map at once (a large number) | 1. Open the combined map page that has many pins<br>2. Pan/zoom the map | The map renders and responds without lag that would disrupt normal use | [NFR-04 AC-1](../acceptance-criteria.md) | NFR-04 | High |
| TC-05-07 | Assign a Supervising Instructor to a company with no one responsible yet — saves immediately (new 2026-09-16) | The target host company has no Supervising Instructor responsible for it beforehand | 1. Log in with an Internship Coordinator account<br>2. Open the Supervising Instructor assignment page for the host company that has no one responsible yet<br>3. Select 1 Supervising Instructor and assign them | The system saves the assignment immediately, showing no confirmation dialog or any additional step | [FR-34 AC-1](../acceptance-criteria.md) | FR-34 | High |
| TC-05-08 | Attempt to assign a Supervising Instructor over a company that already has one responsible → the system asks for confirmation first (new 2026-09-16) | The target host company already has a Supervising Instructor responsible for it (continuing from TC-05-04) | 1. Log in with an Internship Coordinator account<br>2. Open the Supervising Instructor assignment page for the host company that already has one responsible<br>3. Select a new Supervising Instructor (different from the current one responsible) and assign them | The system does not reject immediately and does not save the replacement automatically, but shows the existing Supervising Instructor's information along with a dialog to confirm the cancellation/replacement or to cancel this assignment first | [FR-34 AC-2](../acceptance-criteria.md) | FR-34 | High |
| TC-05-09 | Confirm replacing the existing assignment — saves the new instructor with history (new 2026-09-16) | The system has already shown the replacement confirmation dialog (continuing from TC-05-08) | 1. Click confirm on the cancellation/replacement in the confirmation dialog<br>2. Open the Supervising Instructor assignment history for that host company | The new Supervising Instructor is saved as the one responsible in place of the previous one, and the history shows the previous instructor → the new instructor, who performed the action, and the date and time of the action in full | [FR-34 AC-3](../acceptance-criteria.md), [NFR-02 AC-1](../acceptance-criteria.md) | FR-34, NFR-02 | High |
| TC-05-10 | Cancel the replacement — keep the existing assignment (new 2026-09-16) | The system has already shown the replacement confirmation dialog (continuing from TC-05-08 again with a new host company/instructor set) | 1. Click cancel in the replacement confirmation dialog instead of confirm<br>2. Check who is responsible for that host company again | The system does not save any change; the previous Supervising Instructor responsible remains responsible as before this assignment attempt, and no additional change history is recorded | [FR-34 AC-4](../acceptance-criteria.md) | FR-34 | High |
