# Test Cases — Managing the 3 Internship Acceptance Documents

Step-by-step test cases for the feature [4. Managing the 3 Internship Acceptance Documents](../../design/feature-list.md), referencing the acceptance criteria in [acceptance-criteria](../acceptance-criteria.md) and the flow in [user-journey](../../design/user-journey.md).

| ID | Test case name | Precondition | Steps | Expected result | AC tested | FR/NFR code | Priority |
|---|---|---|---|---|---|---|---|
| TC-04-01 | Upload the Request Letter | The Student has the status "ready to apply for an internship at this host company" (passed FR-10) | 1. Log in with a Student account<br>2. Open the acceptance-document upload page<br>3. Upload the Request Letter | The system saves that file as document #1 for that Student | [FR-11 AC-1](../acceptance-criteria.md) | FR-11 | High |
| TC-04-02 | Upload the Acceptance Letter | The Student has received the Acceptance Letter from the host company (continuing from TC-04-01) | 1. Open the acceptance-document upload page<br>2. Upload the Acceptance Letter | The system saves that file as document #2 for that Student | [FR-12 AC-1](../acceptance-criteria.md) | FR-12 | High |
| TC-04-03 | Upload the Referral (Placement) Letter | The Student has received the Referral (Placement) Letter (continuing from TC-04-02) | 1. Open the acceptance-document upload page<br>2. Upload the Referral (Placement) Letter | The system saves that file as document #3 for that Student | [FR-13 AC-1](../acceptance-criteria.md) | FR-13 | High |
| TC-04-04 | Check status when documents are complete | The Student has uploaded all 3 documents (continuing from TC-04-01 through TC-04-03) | 1. The Internship Coordinator or the Student opens the document status for that Student | The system shows the status "documents complete" | [FR-14 AC-1](../acceptance-criteria.md) | FR-14 | High |
| TC-04-05 | Check status when documents are incomplete | The Student has uploaded only 2 of the 3 documents (e.g. the Referral (Placement) Letter has not yet been uploaded) | 1. The Internship Coordinator or the Student opens the document status for that Student | The system shows the status "documents incomplete" and clearly indicates that the Referral (Placement) Letter is still missing | [FR-14 AC-2](../acceptance-criteria.md) | FR-14 | High |
| TC-04-06 | Notify when documents are near their due date | The Student's documents are not yet complete across all 3, and the deadline for completion is near (continuing from TC-04-05) | 1. Wait until the point at which the system detects that the deadline is near (or simulate a date near the deadline) | The system notifies both the Student and the Internship Coordinator which document is still missing | [FR-15 AC-1](../acceptance-criteria.md) | FR-15 | Medium |
| TC-04-07 | An unauthorized user attempts to access acceptance documents | Acceptance documents for Student A are already saved in the system | 1. Log in with an account that has no authorized relationship to Student A<br>2. Attempt to open Student A's acceptance documents directly | The system denies access | [NFR-01 AC-1](../acceptance-criteria.md) | NFR-01 | High |
| TC-04-08 | Upload an acceptance document with the wrong file type | The Student has prepared a file for one of the documents (e.g. the Referral (Placement) Letter) that is not a PDF/JPG/PNG | 1. Log in with a Student account<br>2. Open the acceptance-document upload page<br>3. Select a wrong-type file and click upload | The system rejects the upload immediately with a message explaining that the file type is invalid, and does not count it as that document | [NFR-06 AC-1](../acceptance-criteria.md) | NFR-06 | High |
| TC-04-09 | Upload an acceptance document that exceeds the size limit / is corrupted | The Student has prepared a file for one of the documents that exceeds 10MB (or is corrupted) | 1. Log in with a Student account<br>2. Open the acceptance-document upload page<br>3. Select the oversized (or corrupted) file and click upload | The system rejects the upload immediately with a message explaining the reason that matches the problem | [NFR-06 AC-2](../acceptance-criteria.md) | NFR-06 | High |
| TC-04-10 | Upload an acceptance document that meets the file conditions | The Student has prepared a file for one of the documents that is a PDF/JPG/PNG, no larger than 10MB, and not corrupted | 1. Log in with a Student account<br>2. Open the acceptance-document upload page<br>3. Select the file that meets the conditions and click upload | The system accepts the file and successfully saves it as that document | [NFR-06 AC-3](../acceptance-criteria.md) | NFR-06 | High |
