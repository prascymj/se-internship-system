# Test Cases — Proposing a Host Company and Requesting Approval

Step-by-step test cases for the feature [2. Proposing a Host Company and Requesting Approval](../../design/feature-list.md), referencing the acceptance criteria in [acceptance-criteria](../acceptance-criteria.md) and the flow in [user-journey](../../design/user-journey.md).

| ID | Test case name | Precondition | Steps | Expected result | AC tested | FR/NFR code | Priority |
|---|---|---|---|---|---|---|---|
| TC-02-01 | Student submits host company information successfully | The Student has the status "host company not yet submitted" | 1. Log in with a Student account<br>2. Open the host company submission page<br>3. Fill in the name, address, contact person, and internship position in every field<br>4. Click save | The system saves the host company information with that Student and changes the status to "awaiting proposal presentation" | [FR-03 AC-1](../acceptance-criteria.md) | FR-03 | High |
| TC-02-02 | Schedule a proposal presentation date with the Academic Advisor | The Student has a submitted host company in the status "awaiting proposal presentation" (continuing from TC-02-01) | 1. Open the page for the submitted host company<br>2. Save the scheduled proposal presentation date | The system saves the scheduled date with that host company's information and shows the same date on both the Student's and the Academic Advisor's side | [FR-04 AC-1](../acceptance-criteria.md) | FR-04 | High |
| TC-02-03 | Academic Advisor records a "pass" result for the proposal presentation | The scheduled proposal presentation date has arrived (continuing from TC-02-02) | 1. Log in with an Academic Advisor account<br>2. Open that Student's proposal presentation record<br>3. Record the result as "pass" with accompanying comments | The system saves the result and comments and changes the Student's status to "ready to apply for an internship at this host company" | [FR-05 AC-1](../acceptance-criteria.md) | FR-05 | High |
| TC-02-04 | Academic Advisor records a "fail" result for the proposal presentation | The scheduled proposal presentation date has arrived (a different Student, continuing from the same step as TC-02-02) | 1. Log in with an Academic Advisor account<br>2. Open that Student's proposal presentation record<br>3. Record the result as "fail" with accompanying comments | The system saves the result and comments and opens the way for the Student to submit a new host company (per FR-06) | [FR-05 AC-2](../acceptance-criteria.md) | FR-05 | High |
| TC-02-05 | Student submits a new host company after a fail, and can loop repeatedly | The Student has just received a "fail" result for the proposal presentation (continuing from TC-02-04) | 1. Open the host company submission page again<br>2. Fill in the new host company information<br>3. Schedule a new proposal presentation date<br>4. Repeat steps 1-3 once more (simulating another fail) | The system allows submitting a new host company and scheduling a new proposal presentation date an unlimited number of times until a pass | [FR-06 AC-1](../acceptance-criteria.md) | FR-06 | High |
| TC-02-06 | Status changes to "ready to apply for an internship" upon passing | The Student's proposal presentation result has been recorded as "pass" (continuing from TC-02-03) | 1. Check the Student's status immediately after the result is recorded | The Student's status changes to "ready to apply for an internship at this host company" automatically, with no additional step required | [FR-07 AC-1](../acceptance-criteria.md) | FR-07 | High |
| TC-02-07 | Check the audit trail for recording the proposal presentation result | The Academic Advisor has just recorded the proposal presentation result (pass or fail) for a Student (continuing from TC-02-03 or TC-02-04) | 1. Open the history/details of that Student's proposal presentation result record | The system shows the name of the Academic Advisor who recorded the result and the date and time it was recorded as part of the audit trail | [NFR-02 AC-1](../acceptance-criteria.md) | NFR-02 | High |
