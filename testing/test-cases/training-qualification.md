# Test Cases — Checking Training Eligibility

Step-by-step test cases for the feature [3. Checking Training Eligibility](../../design/feature-list.md), referencing the acceptance criteria in [acceptance-criteria](../acceptance-criteria.md) and the flow in [user-journey](../../design/user-journey.md).

| ID | Test case name | Precondition | Steps | Expected result | AC tested | FR/NFR code | Priority |
|---|---|---|---|---|---|---|---|
| TC-03-01 | Check the number of training sessions using the default of 5 | The Internship Coordinator has not adjusted the number of training sessions for this semester | 1. The Student uploads certificates for all 5 sessions<br>2. The Internship Coordinator opens the training-session count check for that Student | The system uses the default of 5 sessions as the criterion and shows that the Student meets the criterion | [FR-08 AC-1](../acceptance-criteria.md) | FR-08 | High |
| TC-03-02 | The Internship Coordinator adjusts the training-session count criterion to another value | The Internship Coordinator has permission to adjust the criterion for this semester | 1. The Internship Coordinator adjusts the training-session count criterion to 6 sessions<br>2. The Internship Coordinator opens the training-session count check for a Student who has 5 certificates | The system uses the value of 6 sessions as the criterion (not the default of 5) and shows that the Student does not yet meet the new criterion | [FR-08 AC-2](../acceptance-criteria.md) | FR-08 | High |
| TC-03-03 | Student uploads a training certificate | The Student has finished attending one preparation training session | 1. Log in with a Student account<br>2. Open the certificate upload page<br>3. Upload the certificate file for that session | The system saves that certificate with that Student and counts it as 1 session with complete evidence | [FR-09 AC-1](../acceptance-criteria.md) | FR-09 | High |
| TC-03-04 | The Internship Coordinator confirms completeness, complete case | The Student has uploaded certificates meeting the required number of sessions | 1. The Internship Coordinator checks that Student's certificate count<br>2. Click confirm completeness | The system allows the Student to proceed to the next step (uploading the internship application documents) | [FR-10 AC-1](../acceptance-criteria.md) | FR-10 | High |
| TC-03-05 | The Internship Coordinator checks, incomplete case | The Student has not yet uploaded certificates meeting the required number of sessions | 1. The Internship Coordinator checks that Student's certificate count | The system does not allow proceeding to the next step and shows the Student how many sessions are still missing | [FR-10 AC-2](../acceptance-criteria.md) | FR-10 | High |
| TC-03-06 | An unauthorized user attempts to access another person's certificate | A certificate for Student A is already saved in the system | 1. Log in with Student B's account (not the owner, not a related instructor/coordinator)<br>2. Attempt to open/access Student A's certificate file directly | The system denies access and does not show the file content | [NFR-01 AC-1](../acceptance-criteria.md) | NFR-01 | High |
| TC-03-07 | Upload a certificate with the wrong file type | The Student has prepared a certificate file that is not a PDF/JPG/PNG (e.g. .docx) | 1. Log in with a Student account<br>2. Open the certificate upload page<br>3. Select a .docx file and click upload | The system rejects the upload immediately with a message explaining that the file type is invalid, and does not save that file | [NFR-06 AC-1](../acceptance-criteria.md) | NFR-06 | High |
| TC-03-08 | Upload a certificate exceeding 10MB | The Student has prepared a PDF certificate file that exceeds 10MB | 1. Log in with a Student account<br>2. Open the certificate upload page<br>3. Select the file exceeding 10MB and click upload | The system rejects the upload immediately with a message explaining that the file exceeds the size limit, and does not save that file | [NFR-06 AC-2](../acceptance-criteria.md) | NFR-06 | High |
| TC-03-09 | Upload a certificate that is a corrupted file | The Student has prepared a certificate file with a correct extension but corrupted/unreadable content | 1. Log in with a Student account<br>2. Open the certificate upload page<br>3. Select the corrupted file and click upload | The system detects the file abnormality and rejects the upload immediately with a message explaining the reason | [NFR-06 AC-3](../acceptance-criteria.md) | NFR-06 | High |
| TC-03-10 | Upload a certificate that meets the file conditions | The Student has prepared a certificate file that is a PDF/JPG/PNG, no larger than 10MB, and not corrupted | 1. Log in with a Student account<br>2. Open the certificate upload page<br>3. Select the file that meets the conditions and click upload | The system accepts the file and saves it successfully and immediately (per FR-09) | [NFR-06 AC-4](../acceptance-criteria.md) | NFR-06 | High |
